From case to clinical decision

  1. Prepare the case

    Select the patient, diagnostic category, and matching modality. Upload a supported image and add clinical context.

  2. Run the analysis

    In live mode the original /api/v2/analyze contract powers quality checks, inference, uncertainty, and evidence retrieval. Untrained categories are refused.

  3. Review the evidence

    Inspect confidence, citations, and available Grad-CAM artifacts. Record an attributed assessment, override with rationale, or request a second read.

Demonstration mode does not perform medical inference or generate guideline evidence. All sample records are fictional.
